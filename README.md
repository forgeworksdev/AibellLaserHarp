# Aibell Laser Harp

Aibell is a laser harp (as in, a harp played by manipulating lazers) powered by Arduino Mega™.

It was a project made for the 2º Electromagnetism and Tabletop Games Fair of 2026 of a campus left unnamed for privacy.
